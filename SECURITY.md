# Security policy

## Supported versions

Security and privacy fixes target the latest release.

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability or privacy defect. Send a private report to [Kunal Builds on Instagram](https://instagram.com/bykunalbuilds) with:

- the affected app version;
- reproduction steps;
- the expected and observed behavior;
- any relevant logs with personal images and data removed.

Please allow reasonable time to investigate and publish a fix before public disclosure.
