# Privacy policy

Last updated: August 26, 2026

AI Background Remover processes selected images entirely on the user's Android device.

## Data handling

- The app does not collect, transmit, sell, or share personal data.
- Selected images are read only after the user chooses them with Android's system Photo Picker.
- Image decoding and background removal run locally using the bundled ONNX model.
- Saved transparent PNG files are written to the device's Pictures collection only when the user taps **Save PNG**.
- Sharing creates a temporary file in the app cache and hands it to an app selected by the user through Android's secure sharing mechanism.

## Network and tracking

The app has no Internet permission and contains no analytics, advertising, telemetry, account system, tracking SDK, or remote backend.

## Storage and deletion

The app does not request broad photo-library access. Users control exported files through their device's gallery or file manager. Temporary share files are stored in app cache and can be removed by Android or by clearing the app's cache/data.

## Children

The app does not knowingly collect information from anyone, including children, because it collects no user data.

## Changes

Material changes to this policy will be published in this repository and reflected in a future app release.
